1. 背景介绍¶

2024年1月1日，欧洲足坛照常开启了23/24赛季的冬季转会窗，对于跨年进行的欧洲各大俱乐部赛事来说，这是本赛季内唯一一次可以对阵容进行大范围调整的机会。在2023年冬季转会窗，五大联赛球队共支出了10.61亿欧元。
具体来说，足球转会窗口是指俱乐部可以签约新球员或者出售现有球员的特定时间段，一般分为夏季转会窗口和冬季转会窗口，简称夏窗和冬窗。在转会窗口内，通常有两种交易球员的方式，分别为永久转会（Transfer）和租借（Loan）。永久转会是指球员离开原俱乐部，与新俱乐部签订合同；而租借是指一个俱乐部将其球员暂时租借给另一支俱乐部使用，球员在租借期间仍然是原俱乐部的注册球员，在期满后会返回原俱乐部。而五大联赛通常是指欧洲影响力及竞技水平排名前五的足球联赛，代表了欧洲足球最高的声望和技战术水平。一般而言，这五个联赛包括英格兰足球超级联赛（英超，Premier League）、西班牙足球甲级联赛（西甲，La Liga）、意大利足球甲级联赛（意甲，Serie A）、德国足球甲级联赛（德甲，Bundesliga）和法国足球甲级联赛（法甲，Ligue 1）。
近10年以来，欧洲足坛的一大趋势为足球集团化，具体表现为由一家跨国公司在全球范围内拥有和管理多个足球俱乐部。通过足球集团化，各俱乐部能够最大程度的共享资源、协同发展，从而提高俱乐部的整体实力，并在足球领域取得商业成功。
目前最大的两个足球集团分别为城市足球集团（City Football Group，CFG）和红牛集团（Red Bull Group）。其中前者由阿布扎比联合集团（Abu Dhabi United Group）控股，总部位于英格兰曼彻斯特，拥有英超球队曼彻斯特城、西甲球队赫罗纳、中超球队深圳新鹏城（前四川九牛）等多家足球俱乐部；后者由奥地利的红牛公司创建，拥有德甲球队RB莱比锡（RB Leipzig）等。
值得注意的是，足球集团内部训练方法等资源的共享往往是不可见的，人事方面的内部调整也往往不足够透明，因此，转会窗为我们了解足球集团化的效果提供了公开的数据。理论上，集团内的球队会由于管理层的亲密而倾向于互相交易，集团内的相对较差球队能够以更实惠的价格买到心仪的球员，相对较好的球队也能够更方便地派遣小将外出锻炼提升。
通过足球转会窗口，我们不仅能够通过交易了解每支球队的战术调整和运营策略，揭示各球队之间的交流与竞争关系，还能够整体性地得以窥见各个联赛之间的互动和差异，从而对整个欧洲足球的发展态势有所了解。

2. 数据来源与说明¶

数据通过八爪鱼爬取，来自知名权威转会市场网站德国转会市场（https://www.transfermarkt.com）各球队的Transfer flows页面。因为我们选择以城市足球集团和红牛两大足球集团为抓手，而在本赛季的五大联赛中，共有城市足球集团的英超球队曼彻斯特城和西甲球队赫罗纳以及红牛集团的西甲球队莱比锡红牛三支球队。由于其中最晚被集团化的赫罗纳是在2017年8月被城市足球集团收购，因此选择以17/18赛季为起点，目前的23/24赛季为终点，作为转会数据的时间窗口。同时，为了排除联赛中升降级造成的每支俱乐部转会数据数量级不可比的影响，只对从17/18赛季至今始终保持在该国顶级足球联赛的俱乐部（常驻球队）进行数据分析。对于每支常驻球队，爬取其17/18赛季-23/24赛季的累积转入和转出情况，数据包括转入（出）球队、所属联赛、转会和租借数量、涉及金额等，不包括具体到球员层级的转会信息。最终得到五个联赛分别为转入或转出的10张数据表。

# 定义.csv文件读取函数
process_file <- function(file) {
  df <- read.csv(file, header = TRUE)
  # 根据文件名定义转会Type为Departures或Arrivals
  df$Type <- ifelse(grepl("-D.csv", file), "Departures", "Arrivals") 
  # 获取连字符前的联赛名简称
  competition <- strsplit(file, "-")[[1]][1] 
  # 建立联赛简称全称对应
  competition_mapping <- c("S" = "Serie A", "LL" = "LaLiga", "PL" = "Premier League", "L" = "Ligue 1", "B" = "Bundesliga") 
  # 定义Competition0代表本方联赛（本方：球员转入该联赛该球队；球员从该联赛该球队转出）
  df$Competition0 <- competition_mapping[competition] 
  # 修改变量名，Rank代表转会人次在交易方中的排名，Club0代表本方球队，Competition代表交易方联赛
  colnames(df)[colnames(df) == "字段"] <- "Rank"
  colnames(df)[colnames(df) == "文本"] <- "Club0"
  colnames(df)[colnames(df) == "Competition_2324"] <- "Competition"
  # 删除无关数据列
  df <- df[, -c(3, 5, 7)] 
  # 去除球队名的空字符串
  df$Club <- trimws(df$Club)
  df$Club0 <- trimws(df$Club0)
  # 去除Transfers中的租借数据，仅包含永久转会数据
  df$Transfers <- df$Transfers - df$Loans
  # 得到整理后的最终数据集
  return(df)
}

# 统计五大联赛常驻球队的转入总人次
Clubs <- A_merged %>%
  # 按本方球队、本方联赛分组
  group_by(Club0, Competition0) %>%
  # 加总转入总人次
  summarize(Transfers = sum(Transfers, na.rm = TRUE)) %>%
  # 去重
  distinct(Club0, Competition0, Transfers)

# 统计五大联赛的常驻球队数量和转入总人次
Competitions <- Clubs %>%
  # 按本方联赛分组
  group_by(Competition0) %>%
  # 加总常驻球队球队数量、转入总人次
  summarize(constant = n(), SumT = sum(Transfers)) %>%
  # 计算非常驻球队数量（英超、西甲、意甲共20支球队，其他联赛共18支球队）
  mutate(other = ifelse(Competition0 %in% c("Premier League", "LaLiga", "Serie A"),
                        20 - constant, 18 - constant)) %>%
  # 按常驻球队比例排序
  arrange(constant / (constant + other)) %>%
  # 转换数据格式，分行列示常驻和非常驻球队数量
  pivot_longer(cols = c(constant, other), names_to = "type", values_to = "n")

# 将联赛名转为因子变量
Competitions$Competition0 <- factor(Competitions$Competition0, levels = c("Serie A", "LaLiga", "Premier League", "Ligue 1", "Bundesliga"))
# 将球队类别转为因子变量
Competitions$type <- factor(Competitions$type, levels = c("other", "constant"))

# 合并总转入数据，得到每支五大联赛常驻球队的所属联赛、总转入人次、转入交易方球队数量、所属联赛常驻球队总转入人次
A <- Clubs %>%
  # 合并球队转入交易方球队数量
  left_join(A_merged %>% group_by(Club0) %>% summarize(n_clubs = n()), by = "Club0") %>%
  # 所属联赛常驻球队总转入人次
  left_join(Competitions %>% filter(type == "constant") %>% select(Competition0, SumT), by = "Competition0")

五大联赛内部（转出俱乐部和转入俱乐部均为五大联赛常驻球队）的转会流动也体现出相似的现象。意甲的从五大联赛转入的人次少于向五大联赛转出的人次，而英超则相反。这体现出在五大联赛内部，意甲在经历人才流出，而英超如今在技战术层面、政策层面或是经济层面的吸引力更高，在经历人才流入。具体而言，转会去到英超的球员更均匀的来自五大联赛，而转会到意甲和德甲的来自其他联赛的球员较少，以本国联赛球员为主。
不过除了足球方面的因素，这可能是由语言、生活环境等其他因素导致的。例如，在足球世界，西班牙语和英语是更为通用的语言，球员可能因为语言障碍而选择留在本国或去到其他国家。再比如，西班牙的阳光较之英格兰地区更为充足，球员可能会因为生活体验更好而选择加入西甲联赛。

# 定义数据处理函数，参数为数据集、自身球队名、集团球队列表、永久转会或租借标签
process_data <- function(df, self_name , group_list, flag) {
  df <- df %>%
    # 添加转会分类
    mutate(
      class = case_when(
        grepl(self_name, Club) ~ "self", # 交易方名称包含自身球队名，判定为内部青训球队升入
        Club %in% group_list ~ "group", # 交易方名称在集团球队列表内，判定为集团内部转会
        Club %in% big5_clubs ~ "big5", # 交易方名称为五大联赛常驻球队，判定为五大联赛内部转会
        TRUE ~ "non" # 其他情况
      )
    )
  # 如果为永久转会，分类计算转会总人次
  if (flag == "T") {
    df_class <- df %>%
      group_by(class) %>% # 按交易方类别分组
      summarize(Sum = sum(Transfers, na.rm = TRUE)) %>% # 加总转会人次
      arrange(factor(class, levels = c("self", "group", "big5", "non"))) %>% # 按一定顺序排列数据
      mutate(class = factor(class, levels = c("self", "group", "big5", "non"))) # 转为因子变量
  } 
  # 如果为永久转会，分类计算转会总人次
  else {
    df_class <- df %>%
      group_by(class) %>% # 按交易方类别分组
      summarize(Sum = sum(Loans, na.rm = TRUE)) %>% # 加总转会人次
      arrange(factor(class, levels = c("self", "group", "big5", "non"))) %>% # 按一定顺序排列数据
      mutate(class = factor(class, levels = c("self", "group", "big5", "non"))) # 转为因子变量
  }
  return(df_class)
}

# 分别处理城市足球集团的永久转会、租借转会的转入和转出情况

MC_D_t <- process_data(MC_D, "Manchester City", City, "T")
MC_A_l <- process_data(MC_A, "Manchester City", City, "L")

将两个足球集团的头牌球队：英超球队曼彻斯特城和西甲球队莱比锡红牛单独提取出来，统计其转入或转出球员来源，大致可以分为四类。第一类是球队青训梯队，指一个足球俱乐部内部的年轻球员培训体系，一般有U21（21岁以下）、U19等等；第二类是集团内球队，对于城市足球集团来说，其兄弟球队分别有New York City FC、Melbourne City FC、Girona FC、Yokohama F. Marinos、Montevideo City Torque、Shenzhen Peng City（Sichuan Jiuniu）、Mumbai City FC、Esporte Clube Bahia、Lommel SK、ESTAC Troyes、Palermo FC十一支，而红牛集团的兄弟球队共有FC Liefering、Red Bull Salzburg、New York Red Bulls、Red Bull Bragantino、Red Bull Brasil (SP)五支，从规模上小于城市足球集团；第三类是五大联赛内的常驻球队，代表球员的来源或去向俱乐部属于五大联赛；第四类是其他球队。在下图中，每一个方格代表一个转会人次。
对比分析曼彻斯特城和莱比锡红牛的转入转出情况可以发现，青训球队同时是两支俱乐部重要的人才来源，约占四分之一到三分之一左右。这些升入一线队的球员获得了从青训梯队晋升到俱乐部一队的成功，并拥有在五大联赛正式比赛中代表俱乐部出场的能力。
在集团内部，曼城的集团效应主要发生在转出时，约10%的转会转出人次转入至集团内部，约20%的租借转出人次转入至集团内部，而莱比锡红牛的集团效应更多出现在转入时，全部是以转会转入形式实现的。不过考虑到兄弟球队的数量和五大联赛内集团球队数量的差异，尽管在绝对数量上集团内的交易并不突出，但实际上仍是一个不小的交易比例，显示这集团内球队亲密的合作关系。
这个结果是由集团内球队的相对地位和能力差异带来的。曼城是目前全球最优秀的足球俱乐部之一，目前排名世界第一，总身价12.9亿欧元，而城市集团成绩最好的兄弟球队赫罗纳的世界排名为第18、总身价2.2亿欧元。比较而言，RB莱比锡世界排名第8、总身价5.1亿欧元，红牛集团成绩次好的球队澳超萨尔茨堡红牛世界排名第39、总身价2.1亿欧元。作为世界足坛的领头羊，曼城对于球员的要求可能相对较高，因此集团内的球员难以满足其引援需求，转出或租借能力暂时不足的球员到集团内锻炼会是更好的选择；而莱比锡红牛和萨尔茨堡红牛的实力差距相对较小（不同于排名差异，因为排名和实力并非线性关系），因此可能会有相对更多的萨尔茨堡红牛的球员来到莱比锡红牛寻求进一步发展。
从整体看，曼城更倾向于以永久转会形式引入球员、租借形式转出球员，而莱比锡红牛更倾向于以租借形式引入球员、以永久转会形式转出球员。另外，无论是在转会还是租借方面，曼城转入的规模都要小于莱比锡红牛，转出规模都要大于莱比锡红牛。这或许还能够反映两个足球集团不同的投资策略和风险态度，控股曼城的城市足球集团可能有着更为谨慎的投资思路，并且更为看中转会市场收益。

4. 总结¶
