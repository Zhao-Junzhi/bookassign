案例背景

黄金价格一直是金融市场的重要指标，其价格波动性可以反映市场情绪和宏观经济环境的变化。本案例以黄金价格为研究对象，旨在通过时间序列模型（ARCH、GARCH、EGARCH）分析黄金价格的波动特性，尤其是在疫情前后黄金价格波动的变化。

学习目标

  1. 时间序列数据的处理与可视化。

  2. 平稳性与纯随机性检验，ARCH检验的实施及解释。

  3. ARCH、GARCH 和 EGARCH 模型的建立与效果评估。

  4. 不同模型对波动率预测的对比分析。

  5. 应用时间序列模型分析特定事件对波动率的影响。

任务一

数据预处理。在本任务中，我们将导入并预处理黄金价格数据，转换为时间序列格式，并分析其对数收益率。通过这些操作，您将掌握时间序列数据的加载与基础可视化技能。

数据导入

  • 从 price_daily.csv 文件中读取黄金价格数据。

  • 确保数据的时间列（Date）为标准时间格式。

  • 将黄金价格列（Price）转换为数值型数据，方便后续计算。

  • 使用 xts 包将黄金价格数据转换为时间序列格式。

# 从CSV文件中读取数据
data <- read.csv("price_daily.csv")  # 导入金价数据

# 使用xts包将数据转化为时间序列

任务二

在时间序列建模中，平稳性和纯随机性是关键属性。只有数据平稳且模型显著时，才能进行合理的建模。本任务旨在通过平稳性检验、纯随机性检验和ARCH效应检验，为后续模型选择提供依据。

平稳性检验

  • 使用PP检验（Phillips-Perron Test），原假设为数据不平稳。

  • 检验结果若显著拒绝原假设，则序列为平稳序列。

检验结果表明可以拒绝原假设，即对数收益率序列平稳，因此可以建立模型进行分析

# 使用PP检验验证平稳性
pp.test(log_return)  # 原假设：对数收益率序列不平稳

纯随机性检验

  • 使用Ljung-Box检验（Box.test），原假设为无显著自相关性。

  • 检验结果若不能拒绝原假设，则数据为白噪声。

在0.05水平下可以承认对数收益率为白噪声列。因此，在建模过程中，我们主要关注其波动性特征，而无需对均值进行进一步的建模。

# 自定义ARCH-LM检验函数
archTest <- function(x, m = 10) {
  y <- (x - mean(x))^2  # 计算残差平方
  T <- length(x)        # 样本大小
  atsq <- y[(m + 1):T]
  xmat <- matrix(0, T - m, m)
  for (j in 1:m) {
    xmat[, j] <- y[(m + 1 - j):(T - j)]
  }
  lmres <- lm(atsq ~ xmat)  # 进行回归分析
  summary(lmres)            # 返回回归结果
}

# 对对数收益率序列进行ARCH-LM检验

任务三

在金融市场中，波动性是一个重要的研究对象，因为它可以反映市场的风险水平和投资者情绪。ARCH、GARCH 和 EGARCH 模型是描述波动性动态行为的重要工具。本任务的目标是分别使用这些模型对黄金价格的对数收益率进行建模，分析其波动性特征，并比较模型的效果。

ARCH模型建模与分析

首先使用ARCH模型进行分析。ARCH（自回归条件异方差）模型由Robert F. Engle于1982年提出，主要用于描述金融时间序列中的波动性聚集现象。根据前一部分对ARCH效应检验的结果对ARCH模型进行定阶，拟合ARCH(8)模型，并且检查模型的拟合效果，包括残差的白噪声特性和波动率聚集现象是否被捕捉。我们发现模型能够充分捕捉黄金对数收益率的波动特性，表现为模型拟合后的残差序列为白噪声，同时残差平方序列不再具有ARCH效应。使用fGarch包中的garchFit函数进行拟合，模型拟合结果如下：

GARCH

为了解决ARCH模型的复杂性问题，我们进一步考虑GARCH模型。Bollerslev在1986年提出了GARCH模型，它结合了短期和长期的波动信息，可以在较低阶数下更有效地捕捉时间序列中的波动性特征。GARCH(m,s)模型的形式如下，可以看到模型分析了前m期收益率数据及前s期波动率数据对当期波动的影响。

\[\delta_t^2=\alpha_0+\sum_{i=1}^{m}{\alpha_ia}_{t-i}^2\ +\sum_{j=1}^{s}{\beta_j\delta}_{t-j}^2\]

在本案例中，我们拟合了GARCH(1，1)模型，并且分别假设残差服从标准正态分布和标准t分布，比较两种残差分布假设（正态分布和t分布）的效果。

EGARCH

为了进一步捕捉金价波动的非对称性，我们采用了EGARCH模型。该模型由Nelson于1991年提出，可以更好地描述所谓的“杠杆效应”，即负收益对波动率的影响可能大于正收益的情况。本案例中分析的黄金市场中通常存在明显的波动率非对称性。例如，金价通常在经济不稳定或地缘政治紧张时上涨迅速，而在市场稳定或经济增长时下跌相对缓慢。EGARCH模型的非线性特性能够更准确地捕捉这种非对称性，即所谓的杠杆效应。EGARCH(1,1)模型形式如下：

\[ \ln{\delta_t^2}=\omega+\alpha_1\epsilon_{t-1}+\gamma_1(\left|\epsilon_{t-1}\right|-E|\epsilon_{t-1}|)\ +\beta_1\ln{\delta_{t-1}^2}\]

在本案例中，我们使用ugarchspec函数拟合EGARCH模型。EGARCH模型的拟合结果显示，金价的波动具有非对称性特征，即负收益和正收益对波动率的影响存在差异。EGARCH(1,1)模型拟合结果如下：

# 计算的MSE的函数
calculate_mse <- function(actual, predicted) {
  mse <- mean((actual - predicted)^2)
  return(mse)
}

# 计算每个模型的MSE

模型分析

我们发现，疫情后𝛽₁的值显著下降，而𝛼₁的值大幅上升，说明疫情后短期影响因素对黄金收益率序列的波动贡献度提升，黄金价格的稳定性有所下降。

疫情前𝛼₁符号为负，说明收益率下降会引起更大的波动，这符合我们对金融产品波动性规律的经验。疫情后𝛼₁系数符号为正，违反了经验，推测原因是疫情爆发的社会因素对金价波动性产生了显著的影响，掩盖了金价数据波动性原本的杠杆效应。

通过EGARCH模型，我们不仅能对疫情前后的波动率变化进行量化分析，还能更好地理解在特殊经济事件（如新冠疫情）下市场波动的结构变化。
