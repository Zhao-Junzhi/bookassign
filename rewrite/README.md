# Statistical Problem Rewrite Pipeline

## 概述

本脚本实现了统计问题抽象与建模数据集的系统性改写流程，包含三个主要阶段：改写、思考和循环返修。该流程旨在提升统计问题表述的质量和标准化程度。


## 处理流程

### 阶段1：改写 (Rewrite Stage)
- 提取样本的 input 和 output 字段
- 调用大模型 API 执行改写操作
- 使用提示词模板：`prompt_rewrite`

### 阶段2：思考 (Think Stage)
- **核心目的**：对原始统计问题进行分析，思考其input能被抽象为output的原因
- **使用提示词模板**：`prompt_think`
- **后续用途**：思考结果会作为质量检查阶段的重要参考，验证改写后的问题是否正确保留了原始问题的统计模型信息

### 阶段3：循环返修 (Revision Stage)
- 对改写后的问题进行质量检查
- 使用提示词模板：`quality_check_prompt`
- 若检查未通过，根据反馈进行再次改写
- 最多循环三次，仍未通过则保留原始内容
